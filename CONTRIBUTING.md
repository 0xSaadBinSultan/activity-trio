# Contributing

Bug reports and pull requests are welcome. Include your Android version,
launcher, app version and reproduction steps. Never attach tokens, private
calendar data, signing keys, browser profiles or unredacted authentication logs.

Use JDK 21 and the pinned Gradle wrapper; follow README.md for SDK setup and
run `./gradlew testDebugUnitTest lintRelease assembleRelease` before a PR.

Keep the app token-free: public GitHub/Codeforces/LeetCode profiles only. Do not bundle personal usernames or activity. Preserve square graph cells, visible cache timestamps,
and preserve data provenance. Do not invent daily counts, bypass
access controls, or embed an account token to work around rate limits.

Contributions are accepted under the project's MIT license.
